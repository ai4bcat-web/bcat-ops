## 0. How to read this

**Evidence basis.** Test paths and `describe` names were read from the working tree (merge in progress, so a file the merger is still resolving may shift); every name below was grepped from a real file. "NO test" means no test file reference was found by grep for that feature (not proof none exists). "unverified" means not read or not runnable from here.

**Status.** `covered` = an existing automated test exercises the feature at its handler/page/lib level. `partial` = some tests, but a named piece has none (counted with the gaps). `gap` = no behavioural test; at best a render smoke.

**Merge-risk shorthand.** LM = `Load` model fields (`amplify/data/resource.ts`); AC = `src/lib/apiClient.ts`; NS = `src/lib/navItems.ts` / `navSections.ts`; HD = `amplify/functions/driver-app-api/handler.ts`; RS = `amplify/data/resource.ts`; BE = `amplify/backend.ts`.
