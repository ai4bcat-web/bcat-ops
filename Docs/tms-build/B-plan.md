# Step B — Shipment / Order / Load (dev)

## Architecture and scope

Planned by Claude Fable (`reviewer`, planning-only, as in A). Sources: `MVMNT_TMS_SPEC.md` §3.2–3.4, §6.3–6.4, §6.8, §7 row B; `TMS_DESIGN.md` §4.5/4.6, §5. Three records: **Shipment** (movement, one status, consolidation parent), **Order** (sell side + AR), existing **Load** (buy side) with **LoadCarrier** assignment rows, **LoadFinancials** (cached totals per load) and **LoadCharge** (= MVMNT FinancialLineItem). All additive, no rename/delete; own-fleet readers (calendar, `/loads`, settlements, driver app, PODs, factoring) keep reading `Load.rate`/`readyToInvoice`/`stops`/driver fields unchanged. Money integer cents, percentages bps, timestamps ISO. New models are Lambda-written, `allow.authenticated().to(['read'])`, subscriptions disabled, like Customer. Load stays `allow.authenticated()`; its new status/assignment/money fields are written only by the new Lambda.

## Shared types and pure libs

`src/types/tms.ts`: status/mode enums above; `OrderReference {code, label?, value, level ORDER|HANDLING_UNIT|PACKAGE|STOP, stopId?, visibility INTERNAL|CUSTOMER|CARRIER|ALL}` (`StopReference` same); `FreightItem {id, handlingUnit PALLET|SKID|CRATE|BOX|DRUM|TOTE|BUNDLE|ROLL|OTHER, qty, description?, dims? {l,w,h,unit IN|CM}, weightLbs?, freightClass?, nmfc?, hazmat? {un, hazClass, packingGroup?, emergencyContact}, stackable?, highValue?}`; `SpecialRequirements {team?, tarps?, straps?, liftgate?, hazmat?, tempF? {target,min,max}, other?: string[]}`; `ShipmentRecord`, `OrderRecord`, `LoadCarrierRecord`, `LoadFinancialsRecord`, `LoadChargeRecord`, `ShipmentBundle {shipment, orders, loads, loadCarriers, charges, financials}`.

`src/lib/shipmentCharges.ts` (relative imports; Lambda-shared): `chargeAmount(line, {miles, weightLbs, sideRateBaseCents})` — FLAT `rate×count`, PER_MILE `rate×miles`, PER_CWT `rate×weightLbs/100`, PERCENT `base×rate/10000` (base = Σ same-side `isRate`), `Math.round`; `computeFinancials(charges, ctx, pricing, marginFloorBps)` → Customer Rate, Revenue, Carrier Rate, Cost, Profit, Margin bps (0 at zero revenue), Top spend = revenue − (minProfitCents ?? revenue×marginFloorBps), Target buy by pricing mode (MARGIN `revenue×(1−bps)`, MARKUP `revenue/(1+bps)`, PROFIT `revenue−defaultProfitCents`). `src/lib/shipmentStatus.ts`: transition tables (truckload ladder; LTL ladder reserved), `shipmentStatusFromLoads` (Dispatched/Delivered only when all loads are; TONU when every carrier TONU), `loadStatusFromStopTimes` (first pickup in→LOADING, out→IN_TRANSIT, last delivery in→UNLOADING, out→DELIVERED; never backwards), `isTruckloadMode`, §6.8 short labels. `customerCredit.ts` + `creditExposureForOrders(customer, orders, shipments)`: OPEN/ON_HOLD→OPEN, BOOKED…UNLOADING→ACTIVE, DELIVERED with DOCS_NEEDED/UNBILLED→DELIVERED, UNPAID→INVOICED; DRAFT/CANCELED/deleted/PAID/INVOICE_NOT_NEEDED excluded; load-based exposure kept for loads without `orderId`.

## Lambda `tmsShipmentActions` (`amplify/functions/tms-shipment-actions/`)

Router cloned from `tmsDirectoryActions`: mutation `tmsShipmentActions(action, input: AWSJSON)`, owner/ADMIN/`page-loads`, CAS on `expectedUpdatedAt`/`version`, element-validated JSON ≤100, `TransactWriteItems`, Load writes via generated `updateLoad` (IAM) so subscriptions fire, AuditLog row per action (`EntityType` widened).
- `CREATE_SHIPMENT {customerId, mode?}` — customer ACTIVE only; limit required when `freeCreditRequired` resolves true; mode from customer default/`defaultMode`/FTL; writes Shipment DRAFT + Order + Load leg 1 SOURCING + zero LoadFinancials + `Customer.defaultCharges` as CUSTOMER lines; returns `ShipmentBundle`.
- `SAVE_ORDER_FORM {shipmentId, expectedUpdatedAt, order, stops, charges?, loadFields?}` — DRAFT only; ≥1 pickup + ≥1 delivery, chronological, weight units agree, hazmat fields, `requiredReferences`×`countOnNewOrder`, truckload needs equipmentType; Stop JSON rewritten through `deriveLegacyFields`; recalc.
- `CHECK_CREDIT {customerId, projectedCents}` (read-only `CreditSummary`). `SUBMIT_ORDER {shipmentId, expectedUpdatedAt, carrierRepId?}` — re-save, credit check (projected = revenue), DRAFT→OPEN, load SOURCING; non-truckload modes refused with message.
- `SET_SHIPMENT_STATUS {shipmentId, expectedUpdatedAt, status ON_HOLD|OPEN|CANCELED|UNCANCEL, reason?}`; `SET_LOAD_STATUS {loadId, status}` per transition table (INVOICING and regression refused); shipment re-derived after every load change. `DELETE_SHIPMENT`/`RESTORE_SHIPMENT` (DRAFT/CANCELED/TENDER_REJECTED; `cancelDeleteAdminOnly`). `TENDER_RESPOND {shipmentId, decision ACCEPT|REJECT|RESET, reason?}` (ACCEPT credit-gated → OPEN, acting user carrier rep). `DUPLICATE_SHIPMENT {shipmentId, copies[{pickupAppt, deliveryAppt}] ≤20, sameCarrier?}` credit-checked on the total.
- `UPDATE_STOP {loadId, expectedUpdatedAt, op ADD|REMOVE|SWAP|SET_APPT|SET_REQUESTED|SET_TIMES|SET_TYPE|SET_REFS|SET_LOCATION, stopId?, patch}` — never below one pickup + one delivery; `SET_TIMES` writes `arrivedAt/departedAt` and advances via `loadStatusFromStopTimes`; legacy mirrors, `pickupMonth`, Shipment mirrors rewritten.
- `ASSIGN_ASSET {loadId, driverId, truckId?, trailerId?, driver2?}` — LoadCarrier OWN_ASSET ACTIVE (prior ACTIVE → BOUNCED `REASSIGNED`), sets `stops[].driverId`/`truckId` exactly as the drawer does, SOURCING→BOOKED. `ASSIGN_CARRIER {loadId, carrierName, carrierMc?, dispatcher*, driver*, equipment*, carrierRateCents?}` — LoadCarrier CARRIER ACTIVE, `assignmentType CARRIER`, LINEHAUL CARRIER line (gate + `carrierId` in C). `REMOVE_LOAD_CARRIER {loadCarrierId, outcome BOUNCED|TONU, reason!}` → load SOURCING; TONU keeps its charge line.
- `RECALC_CHARGES {shipmentId, expectedVersion, charges: LoadChargeInput[]}` — full replace per side, no negative CARRIER rates, refused once `frozenAt`; writes LoadCharge rows, LoadFinancials, Order/LoadCarrier cached totals and the `Load.rate` mirror in one transaction. `SET_AR_STATUS {orderId, status DOCS_NEEDED|UNBILLED|INVOICE_NOT_NEEDED}` — UNBILLED after DELIVERED or `invoiceEarly`; INVOICE_NOT_NEEDED only at zero revenue; UNPAID/PAID refused (F).

## Backfill `scripts/backfillShipments.mjs` (plan → review → apply via `tmsPlan.mjs`)

Per Load without `shipmentId`: Shipment `stableId('shp', loadId)`, `number 'L'+aljexId` (no counter), Order `stableId('ord', loadId)`, `source BACKFILL`; Load patch `shipmentId/orderId/leg 1/loadNumber/pickupMonth/assignmentType`; one LoadCarrier OWN_ASSET ACTIVE when any `stops[].driverId` or `truckId` exists (BROKER pseudo-drivers → `NEED_TO_COVER`, no row); LoadFinancials + one CUSTOMER LINEHAUL line from `rate` (else zeros). Status from the evidence-only derived `loadStatus`: unassigned/needs_appt → SOURCING/OPEN; planned → BOOKED; at_pickup → LOADING; in_transit → IN_TRANSIT; at_delivery → UNLOADING; delivered/pod_in/ready → DELIVERED; `statusSource BACKFILL`. AR: DELIVERED + `readyToInvoice` → UNBILLED, DELIVERED otherwise → DOCS_NEEDED, never UNPAID/PAID (same no-inferred-invoicing rule as A). Conditional puts, idempotent re-runs, fingerprinted plan, count report (~890 dev loads); runs before the board reads GSIs.
