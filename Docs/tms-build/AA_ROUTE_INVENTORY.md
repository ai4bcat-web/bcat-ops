**off-nav** (reached by in-page links, own page key) · **public** (outside the shell) · **splat** (entry to a sub-router).
`Home` is the sidebar path; `Old URL → landing` is the concrete URL that exists today and where it lands after AA (`(new)` = a route AA adds).
`Shot` is the walk row that screenshots the page: `AAnn` from devVerifyAA, otherwise the S2 shot number that already covered it.
